THE SHORT VERSION

三步开始播放

先安装，再添加音源，最后开始听歌。

01
DOWNLOAD

下载对应版本

iPhone / iPad 选择 IPA，Android 选择 APK，文件均来自项目 Release。

选择你的设备 ↗
02
ADD SOURCE

添加 LX 音源

打开应用设置，导入你信任的 JSON、JS 或在线音源链接，再进行可用性检测。

查看添加说明 ↗
03
START PLAYING

开始播放

搜索歌曲，选择音质。歌词、封面和播放地址会跟随当前可用音源解析。
