用 AltStore、SideStore、Feather、Sideloadly 或你信任的签名工具导入。 Windows 版 ↗ · macOS 版 ↗

装好以后，添加你自己的音源

打开 Moumusic 的“我的 → 设置 → LX 音源”，可以导入 JSON、JavaScript 文件或在线链接，然后点击检测并启用可用音源。

遇到问题

iOS 无法打开：确认 IPA 已使用你自己的证书签名，并检查证书是否有效。

播放没有声音：先在应用内添加并测试可用的 LX 音源。

页面或名单加载失败：稍后刷新；爱发电支持入口不会受名单 API 影响。
