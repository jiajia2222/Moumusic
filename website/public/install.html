Android 安装

正在获取最新版本…

下载 APK 后按系统提示完成安装。

  1. 01
    下载最新的 Android APK。
  2. 02
    打开 APK；若系统提示，允许浏览器或文件管理器安装未知来源应用。
  3. 03
    安装完成后打开 Moumusic，并在应用内导入你有权使用的音源。

AFTER INSTALL

安装完成后，添加你自己的音源

打开 Moumusic 的“我的 → 设置 → LX 音源”，可以导入 JSON、JavaScript 文件或在线链接，然后点击检测并启用可用音源。

TROUBLESHOOTING

安装后遇到问题？

iOS 无法打开：确认 IPA 已使用你自己的证书签名，并检查证书是否有效。

播放没有声音：先在应用内添加并测试可用的 LX 音源。

页面或名单加载失败：稍后刷新；爱发电支持入口不会受名单 API 影响。

需要帮助？先回到 支持页 前往爱发电
